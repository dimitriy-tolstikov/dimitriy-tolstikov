# Привет, я Дмитрий 👋

Fullstack-разработчик (.NET Core + React / TypeScript) с интересом к DevOps, микросервисам и инструментам для AI-агентов.

## 🛠 Стек

- **Backend:** C#, ASP.NET Core, Clean Architecture, NestJS, Node.js
- **Frontend:** React 19, TypeScript, Zustand, Tailwind, Vue 3, WPF
- **Data & Messaging:** PostgreSQL, Redis, SQLite, Apache Kafka, RabbitMQ
- **DevOps:** Docker / Docker Compose, nginx, GitHub Actions, Gitea, Woodpecker, SonarQube, Trivy
- **Desktop:** WPF, Tauri

## 📌 Основные проекты

### Fullstack

- **[WikiBase](https://github.com/dimitriy-tolstikov/WikiBase)** — база знаний писателя с типизированными объектами: ASP.NET Core 8 + React 19 + PostgreSQL/SQLite, JWT-авторизация, десктоп-приложение на Tauri
- **[Warehouse-System](https://github.com/dimitriy-tolstikov/Warehouse-System)** — система управления складом: ASP.NET Core 9 + React 19 + PostgreSQL, слоистая архитектура, Docker Compose
- **[lowcodeplatform](https://github.com/dimitriy-tolstikov/lowcodeplatform)** — low-code платформа приложений: .NET 8 Clean Architecture + React 19 + PostgreSQL + Redis, локальный DevSecOps-стек (Gitea, Woodpecker, SonarQube, Trivy)
- **[url-checker](https://github.com/dimitriy-tolstikov/url-checker)** — асинхронная массовая проверка доступности URL: NestJS + React 19 + Zustand + Tailwind, Docker Compose
- **[million-item-dual-list](https://github.com/dimitriy-tolstikov/million-item-dual-list)** — двухпанельный список на 1 000 000 элементов: drag-and-drop сортировка, бесконечный скролл, фильтрация, батчинг и дедупликация запросов на сервере (Express + React 19)

### Инструменты для AI-агентов (MCP)

- **[mcp-codebase](https://github.com/dimitriy-tolstikov/mcp-codebase)** — MCP-сервер для семантической навигации по кодовой базе: AST-индекс символов, импортов и зависимостей (TS/JS, C#)
- **[mcp-web-search](https://github.com/dimitriy-tolstikov/mcp-web-search)** — MCP-сервер веб-поиска, оптимизированный для LLM: DuckDuckGo/Serper/Bing, агрегация результатов, stealth-скрапинг, OCR, кэширование и rate limiting

### Backend & архитектура

- **[Microservices-Example](https://github.com/dimitriy-tolstikov/Microservices-Example)** — учебная распределённая система на .NET 8: микросервисы через Apache Kafka и RabbitMQ, outbox pattern, DLX, наблюдаемость

### DevOps

- **[DevOps-Example](https://github.com/dimitriy-tolstikov/DevOps-Example)** — Python-бэкенд за nginx reverse proxy, оркестрация Docker Compose, CI через GitHub Actions
- **[nginx-xff-chain](https://github.com/dimitriy-tolstikov/nginx-xff-chain)** — учебный стенд: трёхзвенная цепочка nginx-прокси с корректной обработкой X-Forwarded-For и защитой от спуфинга (Docker Compose)

### Desktop & фронтенд-практика

- **[Time-tracker](https://github.com/dimitriy-tolstikov/Time-tracker)** — WPF-приложение для Windows: трекинг рабочего времени в выбранном окне по активности клавиатуры/мыши, почасовая статистика и история по дням
- **[vue-example](https://github.com/dimitriy-tolstikov/vue-example)** — учебный проект на Vue 3: Composition API, Vue Router, Vuex, SASS/LESS, Vite
- **[portfolio-site](https://github.com/dimitriy-tolstikov/portfolio-site)** — персональный сайт-портфолио fullstack-разработчика (.NET + React) & DevOps
